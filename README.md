# Gangemester

Et gangetabellspill for 1–10 som kan legges på hjemskjermen på iPhone og virker uten internett.

**Spill:** https://ellingsenchristian-web.github.io/gangemester/

## På iPhone

1. Åpne adressen over i Safari.
2. Trykk **Del → Legg til på Hjem-skjerm**.
3. Åpne spillet én gang mens du er på nett, så lagres en kopi for bruk uten internett.

Skal telefonen bare få åpne dette nettstedet, legg adressen inn under
**Innstillinger → Skjermtid → Innhold og personvern → App Store, medier, nett og spill → Nettinnhold → Bare tillatte nettsteder**.

## Filer

- `index.html` – spillet
- `manifest.webmanifest`, `apple-touch-icon.png`, `icon-*.png` – navn og ikon på hjemskjermen
- `sw.js` – lagrer spillet på telefonen så det virker uten nett

Framgangen (stjerner og stjernekartet) lagres bare på enheten.
